# Responsive Composition

Use this when desktop looks decent but mobile feels cramped, stacked, clipped, or like an afterthought.

## Rule

Mobile is a rewritten story, not desktop stacked vertically.

Do not simply stack every desktop column. Choose the mobile order intentionally.

## Mobile Story Order

For landing/product pages, a common order is:

1. Short promise.
2. Primary action.
3. Compact proof.
4. Cropped product artifact.
5. Outcome or export state.

For tools/dashboards:

1. Current status.
2. Primary controls.
3. Active item/detail.
4. List or secondary navigation.
5. Supporting metrics.

## Mobile Rules

- Use shorter headlines on mobile when needed.
- Prefer one CTA row, not nav plus CTA plus secondary buttons fighting for width.
- Collapse complex mockups into one focused slice.
- Hide or simplify support labels that are obvious from context.
- Keep tap targets at least 44px where possible.
- Avoid horizontal scroll unless it is an intentional carousel/table behavior.
- Make stats proof, not another dense text block.

## Desktop Rules

- Use wide space to create contrast: artifact vs narrative, list vs detail, map vs profile, media vs metadata.
- Avoid two giant framed cards with equal weight.
- Let one product artifact dominate.
- Use side panels only when they clarify the workflow.
- Keep nav, primary CTA, and hero action from competing.

## Breakpoint Checks

Check at least:

- Mobile narrow: 360-390px.
- Mobile large: 414-430px.
- Tablet: 768px.
- Desktop: 1280px+.

Look for:

- Clipped text.
- Buttons escaping containers.
- Header crowding.
- Product artifact too far below the fold.
- Huge empty gaps.
- Repeated stacked cards.
- Hover-only content that touch users cannot access.

## Common Fixes

- Replace long headline with shorter mobile copy.
- Move proof stats above a large mockup.
- Crop the mockup to the most informative area.
- Turn a multi-column product UI into a stepper, tabs, or focused preview.
- Remove secondary nav links from mobile header.
- Make the desktop hero less boxed-in and the mobile hero less tall.
