# Recipe: Editorial Product Story

Use when a landing page needs narrative rhythm instead of a single hero and repeated feature cards.

## Structure

- Treat each major section as a composed scene.
- Change reading mode between sections: hero artifact, quote, workflow, detail zoom, comparison, conversion.
- Use real product artifacts as recurring evidence.
- Keep section copy short and let artifacts demonstrate the product.

## Layout Moves

- Hero stage with product crop.
- Narrow caption or proof strip that bridges into the next section.
- Feature section built around one enlarged artifact detail.
- Quote paired with the exact product object it references.
- Before/after section with input, transformation, and output.
- Final conversion tied to a visible action, not a generic CTA block.

## Type

- Use memorable section headings, not marketing blurbs.
- Keep paragraphs quiet and short.
- Use labels, timestamps, names, file types, statuses, and counts inside artifacts.

## Material

- Alternate density: open scene, dense object, quiet quote, product detail.
- Use background changes as scene changes, not decorative bands.
- Maintain one coherent accent language.

## Mobile

- Each scene should have one read, one artifact, and one action or takeaway.
- Do not preserve decorative desktop side elements if they delay proof.
- Keep the next scene hinted without forcing a long scroll through copy.

## Avoid

- Hero, then three cards, then three cards, then FAQ by habit.
- Sections that all use the same grid.
- Copy-only sections that say what the product could show.
- Long narrative pages with no visible product state.
